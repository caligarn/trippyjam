# TrippyJam

A static site. No build step, no dependencies, no CI. Open `index.html` or
`gallery.html` directly in a browser to preview changes.

## No recurring check-ins

Do not schedule recurring or periodic check-ins for work in this repo. That
means no `send_later` self-wakeups, no cron Routines, no self-rearming
follow-up loops — including the hourly PR check-in that normally follows
opening a pull request.

When you open a pull request here, say so and stop. Do not subscribe to PR
activity and do not schedule a wakeup to re-check its state. If something on a
pull request needs attention, it will be raised in a new session.
